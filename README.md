# Golftracker
Spring Boot -sovellus golfkierrosten seurantaan.

Käynnistys: `./mvnw spring-boot:run` → http://localhost:8080/pelaajat

Testitunnukset:
- user / user (vain katselu)
- admin / admin (lisäys, muokkaus, poisto)

Teknologiat: Java 21, Spring Boot 4, Spring Data JPA, H2, Thymeleaf, Spring Security

Työssä on käytetty tekoälyä apuna oppimisessa ja koodin kirjoittamisessa.
